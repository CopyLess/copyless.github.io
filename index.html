CopyLess for Mac

CopyLess is an advanced clipboard manager for macOS. Store up to 100 clipboard items with instant access, eliminating the need to switch between apps. Copy once, paste anywhere—seamlessly.

Instant Previews

Preview every item as you captured it. Quick Look integration lets you inspect files, images, and text without opening apps. Source app icons provide instant context.

Favorites & Shortcuts

Pin items to a persistent favorites list with one click. Access up to 10 recent items or favorites via custom keyboard shortcuts—no window needed.

Powerful Search

Integrated search finds items instantly. Add custom labels for even faster retrieval. Paste as plain text or send to system clipboard directly.

Effortless Control

Global hotkey opens the menu anytime. Supports all formats: text, images, files, app-specific data. Customize item limits and one-click pasting.

 

How It Works

1. Automatic Capture

Everything you copy is added to CopyLess automatically—no manual intervention.

2. Instant Access

Trigger the menu with your global hotkey. Preview, search, or favorite items on the fly.

3. Paste Seamlessly

Select and paste directly, or use shortcuts for speed. Plain text option strips formatting.

4. Manage Effortlessly

Customize limits, labels, and behavior. Quick Help explains everything in-app.

 

FAQ

Does it support all clipboard formats?

Yes—text, images, files, and app-specific data from any macOS app.

How do I access it quickly?

Set a global hotkey or use shortcuts for recent/favorite items without opening the window.

Can I keep items forever?

Favorites persist across sessions. History holds up to 100 items, customizable.

Is there a preview?

Full previews with Quick Look and source app icons for every item.
